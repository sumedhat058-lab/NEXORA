NEXORA Global Platform — Version 1.0 Prototype

WHAT IS INCLUDED
- Mobile-first futuristic dashboard and navigation
- AI Workspace prompt builder (does not call an AI API yet)
- Text analyzer: word/character/line count and text transforms
- Random password generator using browser crypto
- Basic arithmetic calculator with input-character allowlist
- Creative content starter template
- Simple study plan generator
- Notes and task list saved locally in the browser
- Premium page with requested prices:
  Weekly LKR 330
  Monthly LKR 1,050
  Yearly LKR 5,550
  12-hour demo trial
- Search on the home dashboard

OPEN ON ANDROID
1. Download and extract NEXORA_Global_V1.zip using your Files app.
2. Open index.html with Chrome, or upload the file to GitHub Pages.
3. The website works as a front-end prototype without installing apps.

IMPORTANT LIMITATIONS
- AI Workspace only prepares prompts; it does not connect to an AI provider.
- Notes/tasks are stored only in the current browser on the current device.
- Trial uses localStorage and can be bypassed by clearing browser data. It is NOT secure for real subscriptions.
- Premium payment buttons are placeholders; no payments are taken.
- Before public launch, add authentication, database/cloud sync, server-side trial and Premium checks, payment-provider checkout and verified webhooks, privacy policy, terms, and security testing.
- Do not store passwords or sensitive data in this prototype.
